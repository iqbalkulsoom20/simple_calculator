# simple_calculator
## **Simple Calculator (HTML | CSS | JavaScript)**

A clean and interactive calculator built using HTML, CSS, and Vanilla JavaScript.
The project was created to demonstrate my skills in frontend development, including UI design, layout structuring, event handling, and basic state management in JavaScript.

This calculator works just like a mobile calculator:
you enter the first number → choose an operator → enter the second number → press = to see the result.

## **Features:**
- Modern and clean UI
- Fully functional calculator

## **Supports:**
- Addition (+)
- Subtraction (−)
- Multiplication (×)
- Division (÷)
- C button to clear all input
- Responsive button animations
- Error handling (e.g., division by zero)
- Beginner-friendly code structure
- Well-organized HTML, CSS, and JS files

 ## **Tech Stack:**
 - HTML5
 - CSS3
 - Javascript (Vanilla JS)

## **How the Calculator Works:** 
The calculator follows a simple 3-step logic:
- User enters the first number
- User selects an operator (+ − × ÷)
- User enters the second number and clicks =
  
JavaScript calculates the result and displays it on the screen
The logic uses:
- Event listeners
- State variables (firstNumber, secondNumber, currentOperator)
- A clean calculate() function for math operations
